The Web tools run in the browser; no account is needed. The rail on the left switches between Convert and Generate.

Convert

  1. Paste a payload in the Input editor: UPER or WER as hex, or a message as JSON (JER) or XML (XER). The input format is detected as you paste (shown under the editor); you can also set it by hand.
  2. Choose the output format in the bar under the editor (to UPER, WER, JER or XER).
  3. Press Convert. Each conversion opens a result tab on the right: the input on top, the output below.

The tab header says which definition decoded the payload, for example auto-detected as _denm_v2_3 (_denm_v2_3:DENM). This matters when several versions share the same header, like DENM 2.2 and 2.3.1.

Working with results

  • Copy output, change the font size, or Expand the output.
  • Export every open result as one file: All · HTML or All · CSV.
  • Right-click a tab to close it, the others, or all.

Message versions

The Versions button (Input header) opens Message versions: it lists, for each message type, the versions available and the one auto-detect uses. The public default is the newest version. Signed-in users can pick their own default per message type; it applies to their conversions only.

Encoding rules

The selector next to to chooses the rules:

  • X.691 standard (default): as the standard says, like Objective Systems and asn1tools.
  • asn1c / Vanetza: byte-identical with asn1c-based stacks. asn1c departs from X.691 in a few constraints: it removes the SIZE extensibility after a WITH COMPONENT constraint, merges extension additions into the root, and writes the id of an X.681 open type (CAM 2.3.1 extension containers) without its extension bit.

If a payload from another stack does not decode, or decodes differently, try the other rules.

Generate

  1. Pick the message type and the output format.
  2. Pick the content:
    • Minimal: only the mandatory fields, with minimal values.
    • Random: a typical message: random optional fields, short lists and strings.
    • Full: every optional field present once, one item per list, so each field of the schema appears. Useful to check that a decoder understands the whole message.
  3. Press Generate: the payload lands in the Convert editor, ready to convert.

To set particular values (a station id, a position, a speed), use the API or an AI assistant: see Building messages.

Privacy

Payloads are processed in memory and are neither stored nor logged. Anonymous usage analytics record events such as "conversion failed" with its error message, which may quote a single field value.
