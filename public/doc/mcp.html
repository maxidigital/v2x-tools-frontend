Overview Web tools Building messages AI assistants (MCP) API reference

asn1click is an MCP server: AI assistants that speak the Model Context Protocol (Claude, Cursor, and others) can decode, encode, generate and explain V2X messages with it.

Connect

Server URL (Streamable HTTP, no sign-in needed):

https://mcp.v2x.tools/mcp
  • Claude (web or desktop): add it as a custom connector with that URL.
  • Claude Code: 
    claude mcp add --transport http asn1click https://mcp.v2x.tools/mcp
  • Cursor, in ~/.cursor/mcp.json: 
    { "mcpServers": { "asn1click": { "url": "https://mcp.v2x.tools/mcp" } } }
  • Any other client: add a remote MCP server with the URL above.

What to ask

  • "Decode this payload: uper:0202…": it is auto-detected and the answer says which version was used.
  • "Generate a DENM for roadworks 300 m ahead and give me the UPER".
  • "Why does this payload fail to decode?": the bit-level breakdown shows the field and the bit where it breaks.
  • "What changed in CPM between versions 1 and 2?" or "Explain the fields of a MAPEM lane".

Tools

ToolWhat it does
decodeUPER/WER hex to JSON or XML; auto-detects ETSI messages from their header.
encodeJSON/XML to UPER/WER.
convertBetween any two encodings.
generateA sample message: MINIMAL, RANDOM or FULL, plus set lines (Building messages).
validateChecks a JSON/XML message against its type without changing its format.
diagnoseBit-by-bit breakdown of a UPER payload; for a broken one, where it breaks.
list_messages, list_message_versions, list_modulesWhat exists, and which version auto-detect uses.
search_elements, get_elementFind and read ASN.1 type definitions.
send_feedbackSend a bug report, an idea or an opinion to the developer (the assistant shows you the text first).

Tools that take a message accept just its type (CAM, MAPEM or MAP, SPAT, CPM…) and use its default version, or a specific one (_cam_v2).

Privacy

The server does not store what you send. Your AI assistant, however, sees the payloads, and so does its provider: for confidential data use the Web tools or the API.
